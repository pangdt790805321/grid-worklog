## 工具简介

埃及苏伊士风电项目《网格员工作日志》批量生成工具：

- 选择日期范围 + 网格区域（风机吊装 / 集电线路 / 升压站 / 拌合站 / 电气施工 / 基础 / OHTL / 其他自定义）
- 一键成批生成 Word 日志（合并版 或 ZIP 分份版）
- 支持上传电子签名，自动去白底、裁边，插入每份日志签名栏
- 检查（验证）表按"人、机、料、法、环"五要素共 21 项

## 使用步骤

1. 打开上面的工具链接
2. 填写姓名、选择日期和网格区域（可多选）
3. 上传电子签名图片（白纸签名拍照即可，自动处理）
4. 点击“生成 Word 文档”，下载即用

推荐使用电脑端 Chrome / Edge 浏览器。
